# 桌上冰壶清场交接（bitcatalog 上的虚构赛事子系统）

纯标准库，复用主仓的目录产品与 SQLite 观测仓，不引入新依赖。先回答开头的
规则问题，再说明代码怎么把每条纪律落成可执行断言。

## 最后一壶移走以前，裁判能把这一局的分数签死吗？

**不能。** 裁判在任何时刻只能签"当时全部相容校正共同支持的保证分"：

* 量尺两次曝光之间可能换了原点或方向。若已封存原帧同时相容于多套校正，
  不同校正给出不同比分（本场景是 1 或 2），在歧义消除（补拍到唯一校正）
  或最后一壶移走、争议窗口关闭之前，签死任何一个具体分数都没有证据支撑。
* 可以做的是：登记保证分（所有相容盘的公共下限，本场景为 1 分）、封存实体
  桌与共同参照；等取得合法新帧把校正收敛为唯一整盘后，再签唯一分。
* 提前放桌则永久失去消歧机会，只能按原帧能证明的分数范围（1..2）以保证分
  签收；移壶之后从其他场次补的图在申诉中一律无效。

## 模块分层

| 模块 | 职责 |
| --- | --- |
| `ruler.py` | 俯拍量尺小目录：三活动分支、payload 编解码、按产品指纹 + 实际帧号读回 |
| `geometry.py` | 每次曝光一套带尺度刚体校正；双钉唯一解 / 单钉双假设；整盘壶心还原（全程 `Fraction`） |
| `scoring.py` | 计分台另管犯规撤除与圈半径；严格近距、并列记零、无对方壶全计；含被禁止的逐壶拼盘反例 |
| `referee.py` | 封桌 `seal` / 还桌 `release` 两种交接办法，统一受理计分、放桌、补拍、申诉与并列回放 |
| `scenarios.py` | 题面全部示例的精确数据与原仓入帧流程 |

## 量尺小目录（三活动分支）

一条 5 字节小端位域记录，selector `mark_kind` 决定本次活动的分支：

| selector | 分支 | 分支专属字段（互斥复用同 4 位） | 共用字段 |
| --- | --- | --- | --- |
| 1 | 定位钉 | `pin_id` | `local_x`、`local_y`（有符号千分之一格定点量） |
| 2 | 壶边标记 | `stone_id` | 同上 |
| 3 | 中心钉 | 无 | 同上 |

`pin_id` 与 `stone_id` 分支集合不相交，按目录合同允许复用同一批物理位；
目录经 `build_product()` 编译后得到内容指纹，定义被改动即换指纹，旧帧仍
绑定旧产品可长期复查。同一物理帧号（实际帧号）下可有多条帧事件，原仓按
`(产品指纹, 实际帧号)` 读回，整帧非法时整条拒绝、不产生任何观测。

## 量测纪律：整盘共用一套校正

* 双定位钉 -> 封闭解唯一校正，并用全部已知钉互验；单钉 -> 平移由该钉反解，
  方向候选逐一过钉验证，不相容者剔除（本场景留下两个候选）。
* 一次曝光内所有壶走同一套校正，候选之间才允许方向/原点不同。
* `scoring.naive_per_stone_minimum()` 保留了题面禁止的反面算法（每只壶各自
  挑最小距离再拼盘），测试证明它会报出没有任何整盘校正支持的 2 分，而合法
  的 `score_range()` 只敢保证 1 分。

## 计分规则（`scoring.py`）

仅圈内（距心严格小于半径）有效壶计入；最近方每壶**严格近于**最近对方壶
得一分；最近双方同距记零；对方圈内无壶时本方圈内壶全计。撤除名单与圈半径
是计分台状态，不回改量测端还原的壶心。

题面三档示例（圈半径 5，红 1、3 格）：

| 情形 | 结果 |
| --- | --- |
| 蓝 4 格 | 红 2 分 |
| 只把蓝壶原帧改到 2 格 | 红 1 分 |
| 蓝恢复 4 格，计分台撤除 3 格红壶 | 量测不变，红 1 分 |

## 裁判室入口与三时间点（选定 `seal` 封桌办法）

换坐标那局：曝光 201 双钉唯一（红一 d=1、蓝一 d=6），曝光 202 只有一枚两种
校正都相容的定位钉 P1，红二可能 d=5（较近，红得 2）或 d=7（红得 1）。

| 时间点 | 换坐标局 | 已订此刻开桌的另一局 |
| --- | --- | --- |
| 当天收单 | 双校正未消，**不能签分**，只能登记保证分 1；封桌 | 桌被占，**不能摆壶** |
| 下一班开门 | 保桌取得补拍帧（红二、蓝一、中心钉同幅），校正 2→1，签红 2 分后放桌 | 放桌后方可摆壶 |
| 迟到申诉 | 只受理还桌前封存且同指纹的参照（含已入册补拍帧），维持 2 分 | — |

对照 `release` 还桌办法：当天即可放桌、下一局按时摆壶，但不设补拍窗口；
迟到申诉只认封存共同参照，可证明区间永远停在 1..2，按保证分 1 签收，外场
补图全部驳回。最近壶并列回放每局不超过六壶，第七只壶在入口直接拒绝。
